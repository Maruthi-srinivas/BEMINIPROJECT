## Exercise 1

```python
from copy import deepcopy


def defensive_copy(config: dict) -> dict:
    keys = set(config.get("_immutable_snapshot_keys", []))
    out = {}
    for k, v in config.items():
        if k == "_immutable_snapshot_keys":
            continue
        if k in keys:
            out[k] = deepcopy(v)
        else:
            out[k] = v
    return out
```

Acceptance notes: snapshot keys get independent nested structures; non-listed keys still share nested mutables with the source. Not executed as a standalone test file.

## Exercise 2

The default `items` list is allocated once when the function object is created and reused across calls. Each request appends to the same list object (aliasing). Later requests see prior ids. Fix: `def handle(items=None): items = [] if items is None else items` or build a new list per call without mutating a shared default.

## Exercise 3

Use weak references for values if protobuf messages are large and you can tolerate re-parse on cache miss after GC. Cap entry count with LRU structure holding weak refs; on `KeyError` reload from bytes. Strong references guarantee hit rate but retain full graphs until eviction, risking OOM under many keys. Pair weak cache with explicit invalidation channel (pub/sub) when upstream data changes, because weak entries may already be gone or may return stale objects if not invalidated before reuse.
