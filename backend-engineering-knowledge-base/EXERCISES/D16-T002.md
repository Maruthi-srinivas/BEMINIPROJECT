# Exercises — D16-T002

Problems only. Solutions: [D16-T002](../solutions/D16-T002.md).

1. Write a one-page requirements snippet for a hypothetical ride-hailing dispatch API emphasizing non-functional requirements. Include at least five functional bullets and three measurable NFRs. Acceptance: Functional items are testable; NFRs include numbers or targets; no technology names in the first draft.
2. Given U=500k, p=0.2, A=8, K_peak=4, compute Q_avg and Q_peak and identify which part of non-functional requirements would break first if DB write QPS max is 2000. Acceptance: Show arithmetic; state bottleneck; propose one mitigation tied to the topic.
3. Trade-off: stay monolithic versus split a service for latency, availability, durability, security, and cost targets. List two benefits and two costs and pick one side for an MVP. Acceptance: Mentions operational complexity, data consistency, and team size; choice matches stated constraints.
