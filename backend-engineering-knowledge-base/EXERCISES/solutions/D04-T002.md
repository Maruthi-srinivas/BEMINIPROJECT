## Implementation

def same_subnet(ip: str, other: str, prefix: int) -> bool:
    def bits(text: str) -> int:
        value = 0
        for part in text.split('.'):
            value = (value << 8) | int(part)
        return value
    shift = 32 - prefix
    return (bits(ip) >> shift) == (bits(other) >> shift)


if __name__ == '__main__':
    assert same_subnet('10.0.0.5', '10.0.0.20', 24)
    assert not same_subnet('10.0.0.5', '10.0.1.5', 24)


## Debugging

Cause: The route table lacks a route for the destination CIDR, the security group drops it, or the CIDRs overlap so the local route wins.

Mitigation: Add the missing route or fix the security group. If CIDRs overlap, renumber one side before peering.

Prevention: Allocate prefixes from an IP plan. Record them. Refuse a peer that overlaps.

## Trade-off

Choose when Use private RFC 1918 space inside a VPC and public addresses only on the edge. Reject when Do not overlap CIDRs you may later peer or connect with a VPN. Overlap makes routing ambiguous. The rejected option fails because IPv4 private space overlaps across companies
