# Exercises — D04-T001

Problems only. Solutions: [D04-T001](../solutions/D04-T001.md).

1. Draw a layered diagram for HTTPS from browser to your API through an ingress controller. Label where TLS terminates and where HTTP is parsed. Acceptance: Diagram shows at least four layers and marks termination point.
2. Logs show TCP SYN retransmits to the database IP but HTTP health checks pass to the app. Which layer likely fails and what is your next test? Acceptance: You identify network or security-group path to DB port distinct from app HTTP.
3. Choose L4 versus L7 load balancing for a gRPC service with TLS passthrough. State one benefit and one operational cost. Acceptance: Answer mentions port-based routing versus HTTP/2-aware routing and certificate operations.
