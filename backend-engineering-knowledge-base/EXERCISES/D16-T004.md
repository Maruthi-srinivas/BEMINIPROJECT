# Exercises — D16-T004

Problems only. Solutions: [D16-T004](../solutions/D16-T004.md).

1. Write a one-page requirements snippet for a hypothetical ride-hailing dispatch API emphasizing capacity estimation. Include at least five functional bullets and three measurable NFRs. Acceptance: Functional items are testable; NFRs include numbers or targets; no technology names in the first draft.
