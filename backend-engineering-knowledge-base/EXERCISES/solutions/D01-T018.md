# Solutions for D01-T018

## Exercise 1

Lex/parse → AST → semantic analysis → bytecode (`javac`) → class loading/verification → interpreter execution → profiling counters → JIT compile hot methods → (optional) deoptimization. Native code executes on CPU.

## Exercise 2

Check readiness probe timing, JVM flags, classpath scan (Spring), DB pool init, JIT warmup, TLS handshake on first request, image pull, CPU limits throttling compilation, missing secrets retry loops. Compare p99 first 5 min versus steady; enable compilation logging in staging.

## Exercise 3

JVM: slower cold start, higher peak after warmup, rich ecosystem, dynamic agents. Go: faster binary start, static deploy, simpler concurrency model, fewer framework batteries. Decide based on measured cold p99, team skill, library needs, and memory per pod — not generic speed claims.
