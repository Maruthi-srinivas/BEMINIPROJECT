# Solutions for D02-T008

## Exercise 1

```python
import heapq


def k_smallest(nums: list[int], k: int) -> list[int]:
    h = nums[:k]
    heapq.heapify(h)
    for v in nums[k:]:
        if v > h[0]:
            heapq.heapreplace(h, v)
    return sorted(h)
```

Time O(n log k), space O(k).
