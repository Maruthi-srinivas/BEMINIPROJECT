# Solutions for D01-T019

## Exercise 1

FastAPI: Uvicorn accepts socket → asyncio schedules `async def` route → await async DB/HTTP releases loop → response. Flask (sync): WSGI server thread per request → blocking ORM on that thread → other threads handle other requests (process/thread pool). Async path needs async drivers; sync ORM in async route blocks loop.

## Exercise 2

Symptoms: global latency spike, health checks slow. Use `clinic doctor`, `--trace-event-categories v8`, or logging timestamps around suspect sync call. Mitigate: move CPU/sync IO to `worker_threads`, queue job externally, or stream from another service.

## Exercise 3

Go or Java with good queue consumer libraries if team already operates them; Go for simple binary autoscale and goroutine fan-in; Node if team is JS-only and work is I/O validate-and-enqueue; avoid CPython CPU parsing on hot path unless workers separate. Emphasize idempotent ingest, backpressure, and measured p99 on prototype — no invented QPS numbers.
