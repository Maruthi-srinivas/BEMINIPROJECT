## Exercise 1

```python
import sys


def estimate_list_footprint(n: int) -> int:
    if n < 0 or n > 1000:
        raise ValueError("n must be between 0 and 1000")
    lst = list(range(n))
    return sys.getsizeof(lst) + sum(sys.getsizeof(x) for x in lst)
```

Acceptance notes: footprint grows with `n` because each CPython `int` is a heap object; empty list is smallest. Not executed as a standalone test file.

## Exercise 2

A 4 MiB stack array plus normal frames can exceed the default 8 MiB thread stack, causing guard-page fault or corruption. Move the buffer to heap (`malloc` or static thread-local pool), or reduce size and stream reads. Document `ulimit -s` and measure peak stack with `pthread_attr_getstacksize`.

## Exercise 3

At 50k RPS, naive per-request allocation is ~3.2 GB/s of allocation traffic if every buffer is discarded immediately, stressing allocator and GC (in managed runtimes). A fixed pool of reusable 64 KiB buffers cuts allocation rate but requires zeroing sensitive bytes, handling pool exhaustion (block, drop, or allocate fallback), and optional per-tenant pools for isolation. Per-request heap is simpler and safe for low QPS; pools win at sustained high RPS if exhaustion policy is defined.
