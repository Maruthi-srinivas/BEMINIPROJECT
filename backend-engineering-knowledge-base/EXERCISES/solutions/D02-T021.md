# Solutions — D02-T021

## Exercise 1

Backtracking searches a decision tree and undoes a choice when it violates a constraint. It is depth-first enumeration with pruning. Correctness comes from exploring every feasible partial assignment, not from greediness. Pruning is safe only when a partial assignment can never be extended to a solution.

The failure enters when a step is skipped or repeated without an invariant: pruning a branch that still contains a solution, or exploring a tree so large that latency exceeds the request deadline.

Mark that step on the diagram. If you cannot point to a step, the explanation is still a definition, not a mechanism.

## Exercise 3

Choose Backtracking when the search space is small after pruning, or you need every feasible answer.

Avoid it when a closed-form or greedy rule already exists, or n is large and you only need one good answer.

A good answer names the metric that would change your mind: nodes visited versus solutions found, and p99 latency of the search call.
