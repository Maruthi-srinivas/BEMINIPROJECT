# Solutions for D01-T016

## Exercise 1

Spawn 100 threads each calling `inc` 1000 times; expect `value() == 100_000`. Without lock, result is lower. Unexecuted.

## Exercise 2

All pool threads block on slow outbound HTTP; no threads accept new work. Fix: dedicated client with async or separate smaller pool for outbound calls, timeouts, circuit breaker, or reactive stack. Increase threads only after fixing blocking in critical path.

## Exercise 3

10k OS threads carry large stack memory; async/event loop or goroutines multiplex on fewer threads with lower idle memory. Thread-per-request simpler for blocking code but costly at 10k idle sockets. Use async I/O or WebSocket framework with efficient connection management.
