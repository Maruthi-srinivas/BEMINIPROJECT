# Solutions — D13-T022

## Exercise 1

Structured concurrency keeps child tasks inside a parent's lifetime. The parent waits for the children, or cancels them, before it returns. Errors surface to the parent instead of disappearing into a detached callback. A nursery or a scope is the usual API. It stops the leak where a request ends and a background task still writes.

The failure enters when a step is skipped or repeated without an invariant: a detached task that outlives the request and writes a response nobody needs, or an error that is never observed.

Mark that step on the diagram. If you cannot point to a step, the explanation is still a definition, not a mechanism.
