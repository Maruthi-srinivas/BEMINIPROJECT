# Solutions for D20-T001

Open this only after attempting the exercises in the topic note.

## Exercise 1

Add three pytest functions: round-trip encode/decode for a known cursor payload, `pytest.raises` on malformed base64 or schema, and default-to-first-page when the token is empty. Keep tests free of HTTP and database fixtures.

## Exercise 2

The smell is an over-specified mock that hides integration drift. Replace the constant mock with a contract test against the tax provider fixture or an integration test using recorded HTTP responses. Keep unit tests on pure calculation once the rate is injected.

## Exercise 3

Public API tests survive refactors and assert user-visible behavior. Private method tests break on rename without catching new regressions customers would see. Test `quote_order` outcomes (totals, tax lines) rather than internal helpers.
