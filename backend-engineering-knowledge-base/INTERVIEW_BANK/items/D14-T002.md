11–15 Advanced: outbox bridge, temporal coupling, sagas, async feeling sync, backpressure.
16–20 Scenarios: email in checkout path, 202 without failure signal, circular RPC, 200 before commit, read-your-writes with async index.
21–23 Follow-ups: queues vs streams, partial failures, API design.
