# Solutions — D17-T001

1. Include `POST /v1/links`, `GET /{code}` 302, `links(code PK)`, Redis cache-aside; assume 10:1 reads:writes (or state your own ratio explicitly).
2. Local LRU on redirect nodes, singleflight on cache miss, CDN pre-warm; then read replicas feeding cache.
3. Prefer 302 or short CDN TTL; 301 traps clients on old creative until browser/CDN cache expires.
