# D07-T001 interview items

Domain: Database Fundamentals
Topic: Relational vs non-relational databases

## Questions

1. Beginner. What is a relational database?
2. Beginner. What does non-relational mean in practice?
3. Beginner. Name two differences between SQL and NoSQL marketing labels.
4. Beginner. Where does the application sit in the data path?
5. Beginner. What is a single reason to keep using a relational database in 2026?
6. Intermediate. How do you decide between PostgreSQL and MongoDB for a new product?
7. Intermediate. What is the impedance mismatch problem?
8. Intermediate. Can a system use both relational and non-relational databases?
9. Intermediate. How does schema flexibility differ?
10. Intermediate. What question exposes a weak 'NoSQL for scale' answer?
11. Advanced. How does CAP apply to database choice?
12. Advanced. What is BASE as contrasted with ACID?
13. Advanced. When is a graph database the right relational alternative?
14. Advanced. What operational signals differ between stores?
15. Advanced. How do you migrate from document to relational later?
16. Scenario. Marketing wants Mongo because 'JSON matches the API' but finance needs SQL reports. What do you propose?
17. Scenario. Latency on reads spiked after choosing Redis as the primary database. What went wrong?
18. Scenario. A startup copied a big-tech polyglot diagram. Incidents multiply. Why?
19. Scenario. Team argues Dynamo-style always beats SQL. What benchmark do you run?
20. Scenario. Compliance requires row-level audit who changed what. Does NoSQL help?
21. Follow-up. How does this connect to schema design in D07-T002?
22. Follow-up. How does this connect to transactions in D07-T011?
23. Follow-up. How does caching relate to picking SQL versus NoSQL?
