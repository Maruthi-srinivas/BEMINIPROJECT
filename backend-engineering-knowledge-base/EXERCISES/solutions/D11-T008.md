# Solutions — D11-T008

## Exercise 1

A cache stampede is many requests missing the same key and all loading the database at once. It happens on expiry, on deploy, or on a cold key that is suddenly hot. Single-flight lets one request load and the others wait. A lock with a short timeout, early refresh, and jitter are the usual controls. The database must still survive one loader.

The failure enters when a step is skipped or repeated without an invariant: a lock that expires before the load finishes, so several loaders run anyway, or waiters that pile up past the client deadline.

Mark that step on the diagram. If you cannot point to a step, the explanation is still a definition, not a mechanism.
