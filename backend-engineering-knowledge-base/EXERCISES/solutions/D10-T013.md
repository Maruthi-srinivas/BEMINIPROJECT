# Solutions for D10-T013

## Exercise 1

N=3: R=1 W=2 gives W+R>N (3) for strong-ish reads if you read after write with W=2; read-heavy config may use R=1 W=1 accepting stale reads during failure.

## Exercise 2

Sloppy quorum or divergent writes without repair; run read repair, anti-entropy, or re-sync from authoritative backup.

## Exercise 3

Password reset tokens need durability—prefer W=2 or stronger; latency trade acceptable for security-sensitive short-lived data.
