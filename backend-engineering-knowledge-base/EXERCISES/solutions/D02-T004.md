## Exercise 1

```python
class Node:
    def __init__(self, val: int, nxt=None):
        self.val = val
        self.nxt = nxt


def prepend(head: Node | None, val: int) -> Node:
    return Node(val, head)


def find(head: Node | None, target: int) -> Node | None:
    cur = head
    while cur:
        if cur.val == target:
            return cur
        cur = cur.nxt
    return None
```

`prepend` is O(1). `find` is O(n) time, O(1) extra space.
