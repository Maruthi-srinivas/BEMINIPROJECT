# Solutions — D03-T013

## Exercise 1

An atomic operation completes as a single step with respect to other threads. Compare-and-swap takes an address, an expected value, and a new value, and updates the address only if it still holds the expected value. It is the building block of lock-free stacks and counters. ABA is the bug where the value changes from A to B and back to A, so a CAS succeeds and misses the intervening mutation.

The failure enters when a step is skipped or repeated without an invariant: ABA on a pointer, or a CAS loop that burns a core under contention.

Mark that step on the diagram. If you cannot point to a step, the explanation is still a definition, not a mechanism.

Choose Atomic operations and compare-and-swap when the update is a single word and the critical section is tiny.

Avoid it when the invariant spans two words, unless you have a double-width CAS or a lock.
