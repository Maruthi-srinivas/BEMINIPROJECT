# Solutions for D11-T001

Open this only after attempting the exercises in the topic note.

## Exercise 1

See topic note section F; add `metrics.incr('product_cache_hit')` on the hit branch and `product_cache_miss` on the miss branch before returning.

## Exercise 2

Verify the cache key includes `product_id`, confirm every pod uses the same Redis endpoint and key prefix, and check whether a deploy flushed Redis or changed serialization format.

## Exercise 3

Choose Redis when flags must be consistent across pods within seconds. Choose local Caffeine when flags are immutable for the lifetime of a deploy and staggered visibility across instances is acceptable.
