## Exercise 1

```python
def count_distinct(events: list[str]) -> int:
    seen: set[str] = set()
    for e in events:
        seen.add(e)
    return len(seen)


def has_pair_duplicate(nums: list[int]) -> bool:
    n = len(nums)
    for i in range(n):
        for j in range(i + 1, n):
            if nums[i] == nums[j]:
                return True
    return False
```

`count_distinct`: O(n) time, O(n) space. `has_pair_duplicate`: O(n^2) time, O(1) extra space.
