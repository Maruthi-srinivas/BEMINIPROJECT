## Exercise 1

```python
class Order:
    def __init__(self, order_id: str) -> None:
        if not order_id:
            raise ValueError("order_id required")
        self._id = order_id
        self._lines: list[tuple[str, Money]] = []

    def add_line(self, sku: str, price: Money) -> None:
        if any(existing == sku for existing, _ in self._lines):
            raise ValueError("duplicate sku")
        self._lines.append((sku, price))

    def line_count(self) -> int:
        return len(self._lines)

    def total(self) -> Money:
        if not self._lines:
            raise ValueError("empty order")
        currency = self._lines[0][1].currency
        total_cents = 0
        for _, price in self._lines:
            if price.currency != currency:
                raise ValueError("mixed currency")
            total_cents += price.amount_cents
        return Money(total_cents, currency)
```

Acceptance notes: duplicate check is O(n); a `set` of SKUs is fine for large carts. Sibling example `d01_t006_oop.py` was executed.
