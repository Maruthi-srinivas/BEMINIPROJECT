# Exercises — D16-T011

Problems only. Solutions: [D16-T011](../solutions/D16-T011.md).

1. Write a one-page requirements snippet for a hypothetical ride-hailing dispatch API emphasizing low-level design. Include at least five functional bullets and three measurable NFRs. Acceptance: Functional items are testable; NFRs include numbers or targets; no technology names in the first draft.
