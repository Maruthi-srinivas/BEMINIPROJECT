1. Beginner. What is API composition in a microservices system?

4. Beginner. What is a common misconception about API composition?
5. Beginner. How does API composition relate to the API gateway or service mesh?
6. Intermediate. How would you implement API composition on a greenfield checkout platform?
7. Intermediate. What trade-off does API composition introduce versus a modular monolith?
8. Intermediate. Which failures should you design for when applying API composition?
9. Intermediate. How do you test API composition end to end?
10. Intermediate. What metrics and logs prove API composition is healthy?
11. Advanced. Design a migration path that adopts API composition without a big-bang rewrite.
12. Advanced. How does API composition interact with sagas, outbox, or CQRS?
13. Advanced. Explain security implications of API composition.
14. Advanced. When would you deliberately not apply API composition yet?
15. Advanced. How do you prevent sequential N+1 service calls without deadlines?
16. Scenarios. Checkout latency doubles after introducing api composition; databases look fine. What next?
17. Scenarios. Two services disagree on customer balance after order detail page merges user profile and line items. How do you reconcile?
18. Scenarios. On-call sees cascading 503s from the edge. How could API composition contribute to the blast radius?
19. Scenarios. Product wants a cross-service report joining five databases. What do you propose?
20. Scenarios. A team ships a breaking API change during API composition rollout. How do you recover?
