# Solutions for D19-T016

Open this only after attempting the exercises in the topic note.

## Exercise 1

Context map: place Order, Payment, Inventory (or analogs for order saved and OrderCreated event never lost on crash) in separate boxes with private databases. Sync: Order→Payment authorize. Async: OrderPlaced→Inventory reservation consumer. Contracts: `AuthorizePayment`, `OrderPlaced` v1. No shared tables.

## Exercise 2

ADR: Context—teams coupled via shared schema. Decision—enforce database-per-service and expose same DB transaction via API/events. Consequences—need saga/outbox for cross-service invariants; migrate via strangler; add contract tests in CI.

## Exercise 3

Metrics: checkout p95 latency; payment error rate; outbox lag seconds. Alerts: SLO burn on checkout; outbox lag > 60s. Runbook: fetch trace id from support ticket, inspect payment span, pause consumer if poison message, replay with idempotency key.
