# Interview notes

Backend interview study set. The full checklist is in [syllabus.md](./syllabus.md).

The canonical topic inventory and, as they are written, the detailed notes live in [backend-engineering-knowledge-base](../backend-engineering-knowledge-base/README.md). This folder keeps the checkbox syllabus.

 Each topic below is a standalone notes file written from that checklist.

How to use this:

1. Read a topic until you can explain every heading without looking.
2. Check the matching boxes in `syllabus.md`.
3. Practice the "say this" lines out loud. Interviewers grade clarity, not vocabulary.
