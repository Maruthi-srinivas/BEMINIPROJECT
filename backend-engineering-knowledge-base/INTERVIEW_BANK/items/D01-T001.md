# D01-T001 interview items

Domain: Programming Language Fundamentals
Topic: Data types, variables, operators, type conversion
Difficulty mix: beginner, intermediate, advanced, scenario, follow-up
Interview type: fundamentals, debugging, trade-off
Full reasoned answers are in the topic note, section K.

## Questions

1. Beginner. What is a data type?
2. Beginner. What is the difference between a variable and a value?
3. Beginner. What is type conversion?
4. Beginner. Why is 0.1 + 0.2 not 0.3 in most languages?
5. Beginner. Where do types show up in a web API?
6. Intermediate. How does Java autoboxing change a hot counter?
7. Intermediate. Why can a JavaScript client corrupt a 64-bit identifier?
8. Intermediate. When is implicit conversion acceptable?
9. Intermediate. How do Python and Java integers differ as a counter grows?
10. Intermediate. How should money be typed?
11. Advanced. Why is integer overflow a security bug?
12. Advanced. How does a dynamic language implement operators?
13. Advanced. What does a compiler do on widening versus narrowing conversion?
14. Advanced. Why is Integer caching in Java a trap?
15. Advanced. How do you change an id field from number to string without breaking clients?
16. Scenario. A 10% discount is off by a cent. What do you inspect first?
17. Scenario. Go and Python disagree on an id that passed through JSON. Why?
18. Scenario. NumberFormatException spikes after a mobile release. Where is the fault?
19. Scenario. Request totals go negative after a traffic spike. What wrapped?
20. Scenario. Finance CSV uses comma decimals. What rules do you publish?
21. Follow-up. How does this connect to database column types?
22. Follow-up. Does a typed int remove data races?
23. Follow-up. Why are API schemas needed if the language is typed?
