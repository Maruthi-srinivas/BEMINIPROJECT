# Solutions — D11-T006

## Exercise 1

A TTL on a cache entry deletes or ignores it after a duration. It bounds staleness when an invalidation is lost. It does not make the entry correct. A short TTL raises the miss rate and the database load. A long TTL lengthens the stale window. Jitter stops every key from expiring on the same second.

The failure enters when a step is skipped or repeated without an invariant: every key expiring together and stampeding the database, or a TTL so long that users see yesterday's price.

Mark that step on the diagram. If you cannot point to a step, the explanation is still a definition, not a mechanism.
