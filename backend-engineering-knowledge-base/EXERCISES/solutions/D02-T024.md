# Solutions — D02-T024

## Exercise 1

Interval algorithms keep segments on a line. Sorting by start or end, then scanning once, answers overlap, merge, and minimum meeting rooms. A sweep line moves a cursor and updates a counter or a heap at each start and end event. A segment tree answers stabbing queries when the scan is not enough.

The failure enters when a step is skipped or repeated without an invariant: a tie-break that closes an interval before it opens at the same timestamp, so a meeting that ends when another starts looks like an overlap.

Mark that step on the diagram. If you cannot point to a step, the explanation is still a definition, not a mechanism.
