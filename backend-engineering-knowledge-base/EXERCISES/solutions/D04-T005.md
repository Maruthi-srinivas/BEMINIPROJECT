# Solutions for D04-T005

## Exercise 1

Client SYN seq=x; server SYN-ACK seq=y ack=x+1; client ACK ack=y+1. Both sides ESTABLISHED.

## Exercise 2

Verify Redis host/port, SG/NACL, and that Redis listens on the interface reachable from the pod subnet. SYN-SENT without SYN-ACK is before application logic.

## Exercise 3

New TCP adds one RTT (plus TLS) per call; pools reuse sockets and cut tail latency at cost of max pool size, idle timeouts, and handling broken connections.
