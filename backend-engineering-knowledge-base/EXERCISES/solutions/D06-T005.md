# Solutions for D06-T005

## Exercise 1

`Money`: `amount_cents` integer minimum 0, `currency` string pattern `^[A-Z]{3}$`. `Timestamp`: string `format: date-time` UTC. Reference via `$ref` from order and invoice schemas.

## Exercise 2

Client uses strict deserialization with closed objects; server added `metadata` map. Fix client to ignore unknown fields or version API; server change is backward compatible per `D06-T021`.

## Exercise 3

`additionalProperties: false` catches typos but rejects forward-compatible clients; use on write paths for partners you control, not on public webhooks payloads.
