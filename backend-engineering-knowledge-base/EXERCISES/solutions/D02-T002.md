# Solutions for D02-T002

## Exercise 1

Linear search: O(n) worst, Omega(1) best. Binary search on sorted array: O(log n) worst, Omega(1) if middle hits.

## Exercise 2

Worst-case Big-O was quoted while typical path hits cache/index (Theta(1) or O(log n)). Measure distribution of n and cache hit rate.

## Exercise 3

Full scan is Theta(n) rows read. Index lookup is O(log n) B-tree pages or O(1) hash if in memory.
