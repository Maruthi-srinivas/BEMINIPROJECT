## Exercise 1

```python
class ConflictError(DomainError):
    pass


class ValidationErrors(DomainError):
    def __init__(self, errors: list[tuple[str, str]]) -> None:
        super().__init__("validation failed")
        self.errors = errors


def to_api_error(exc: BaseException) -> ApiError:
    if isinstance(exc, ValidationErrors):
        return ApiError(400, "validation_error", str(exc.errors))
    if isinstance(exc, ConflictError):
        return ApiError(409, "conflict", str(exc))
    # ... existing NotFoundError, ValidationError, DomainError branches
```

Tests: `assert to_api_error(NotFoundError("user", "x")).status == 404`. Sibling example `d01_t010_exceptions.py` was executed.

## Exercise 2

Broad `@ExceptionHandler(Exception.class)` runs before or instead of `NotFoundError` if order is wrong or type wrapped in `RuntimeException`. Fix: handlers ordered most specific first; do not wrap domain errors. Integration test: `GET /users/missing` expects 404 and `not_found` code.

## Exercise 3

Public library: checked exceptions document recoverable IO failures callers must handle; API stability forces explicit contracts. Internal microservice: unchecked domain exceptions plus `@ControllerAdvice` reduce signature pollution and match Spring ecosystem. Hybrid: checked at library boundary, translate to unchecked domain at adapter.
