# Solutions for D01-T017

## Exercise 1

`def size(self) -> int: self._purge(); return len(self._store)`. Unexecuted.

## Exercise 2

In a servlet filter: `try { chain.doFilter(...) } finally { userContext.remove(); }` so pooled threads do not retain the previous request's `UserContext` in `ThreadLocal`.

## Exercise 3

Unbounded map grows until OOM and has no staleness policy. Caffeine `maximumSize` plus `expireAfterWrite` bounds memory and refreshes data; slightly more CPU on access for maintenance. Use Caffeine for production caches unless you prove tiny fixed key set.
