## Exercise 1

```python
class RefundableGateway(PaymentGateway):
    def refund(self, provider_ref: str, amount_cents: int) -> None: ...


class FakeGateway(PaymentGateway):
    def __init__(self) -> None:
        self.charges = 0

    def charge(self, request: ChargeRequest) -> ChargeResult:
        self.charges += 1
        return ChargeResult(provider_ref="fake-ok")
```

`BillingService.bill` rejects `amount_cents <= 0`. Only adapters that implement `RefundableGateway` expose refunds; billing does not call refund unless the port is present. Sibling example `d01_t007_pillars.py` was executed.

## Exercise 2

Skipping `super().afterSave()` means the parent's audit hook never runs. That is fragile base class coupling: subclasses must know parent internals. Fix: make audit mandatory in a final `save()` that calls private `_doSave()` overrides, or compose an `AuditSink` injected into all writers.

## Exercise 3

```python
class StorageBackend(ABC):
    @abstractmethod
    def put(self, key: str, data: bytes) -> None: ...


class S3Storage(StorageBackend): ...
class LocalStorage(StorageBackend): ...
```

Handler receives `StorageBackend` from DI. Feature flags select bean implementation in config, not `if provider == "s3"` in the handler.
