## Exercise 1

```python
def build_adj(n: int, edges: list[tuple[int, int]]) -> list[list[int]]:
    adj: list[list[int]] = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    return adj


def degree(adj: list[list[int]], u: int) -> int:
    return len(adj[u])
```

Build O(E), space O(V+E).
