# Solutions for D01-T009

Open this only after attempting the exercises in the topic note.

## Exercise 1

Use section F `InMemoryUserRepo` and `UserService`; `create` returns id from `save`, `get` retrieves dict. Optional: run `mypy d01_t009_generics.py` if installed. Sibling example was executed.

## Exercise 2

Prefer composition: `RetryingHttpClient(delegate: HttpClient, policy: RetryPolicy)` with interface `HttpClient` for each API. Abstract class is acceptable if template method shares substantial retry loop and subclasses only implement `executeOnce()`. Avoid abstract class when the only shared code is three lines.

## Exercise 3

Compile-time `Cache<UUID, User>` prevents putting `User` in wrong map in Java source. JSON and Redis still store strings; deserialization must target `User` explicitly. If email is key and user updates email, generic types do not invalidate; application must delete old key. Runtime erasure means monitoring cannot distinguish `Cache<String,User>` from raw map without discipline.
