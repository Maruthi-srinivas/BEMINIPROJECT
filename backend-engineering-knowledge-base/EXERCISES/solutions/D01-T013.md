## Exercise 1

```python
def read_lines(path: str):
    with open(path, encoding="utf-8") as f:
        for line in f:
            s = line.strip()
            if s:
                yield s
```

Combine with `batched(read_lines(path), 4)` for acceptance. Unexecuted.
