# D31-T001 interview items

Domain: Backend Frameworks — Choose One Deeply
Topic: Spring Boot: IoC, beans, DI, auto-configuration
Difficulty mix: beginner, intermediate, advanced, scenario, follow-up
Interview type: fundamentals, debugging, trade-off
Full reasoned answers are in the topic note, section K.

## Questions

1. Beginner. What problem does Spring Boot solve in a backend system?
2. Beginner. What are the main components involved in Spring Boot?
3. Beginner. How does Spring Boot show up at an API boundary?
4. Beginner. What is a common misconception about Spring Boot?
5. Beginner. Which metric would you watch first after enabling Spring Boot?
6. Intermediate. Walk through the request path for Spring Boot under normal load.
7. Intermediate. How would you test Spring Boot before a production rollout?
8. Intermediate. What consistency or durability guarantees matter for Spring Boot?
9. Intermediate. How does Spring Boot interact with retries and timeouts?
10. Intermediate. Where would you place authorization checks relative to Spring Boot?
11. Advanced. What failure modes are unique to Spring Boot at scale?
12. Advanced. How would you design Spring Boot for multi-region or multi-tenant isolation?
13. Advanced. Compare two implementation options for Spring Boot and pick one with reasons.
14. Advanced. How do you prevent Spring Boot from becoming a single point of failure?
15. Advanced. What load or chaos tests would you run for Spring Boot?
16. Scenario. Latency spikes right after a deploy touching Spring Boot. What do you check first?
17. Scenario. One tenant reports errors while others are healthy. How does Spring Boot factor in?
18. Scenario. Costs doubled after enabling Spring Boot. How do you investigate?
19. Scenario. A dependency used by Spring Boot is slow but not down. What mitigations apply?
20. Scenario. An audit asks for evidence that Spring Boot is enforced. What artifacts do you provide?
21. Follow-up. How does Spring Boot relate to observability and SLOs?
22. Follow-up. Which earlier database or networking topics does Spring Boot assume?
23. Follow-up. What would you study next after mastering Spring Boot?
