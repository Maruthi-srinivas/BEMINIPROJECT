# Interview bank

Questions and reasoned answers live in each topic note, section K.
A short pointer file per topic is under `items/` when that note has been generated.

For self-testing, read the question headings in the note and answer out loud before you read the **Answer** lines.

The bank is incomplete until every inventory ID has an item file and a note. Check [the progress tracker](../00_INDEX/PROGRESS_TRACKER.md).
