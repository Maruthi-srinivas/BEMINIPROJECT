## Exercise 1

```python
def join_fields(fields: list[str]) -> str:
    return ",".join(fields)


def bad_join(fields: list[str]) -> str:
    out = ""
    for f in fields:
        out += f + ","
    return out.rstrip(",")
```

Prefer `join_fields`: one pass, O(total characters) time and output space. `bad_join` is O(n^2) character copies for many fields.
