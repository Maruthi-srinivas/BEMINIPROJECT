# Solutions for D03-T005

## Exercise 1

Use `sched_getscheduler(0)` or `chrt -p PID` on Linux; document SCHED_OTHER default.

## Exercise 2

Too many runnable threads vs cores, cgroup CPU throttling (`nr_throttled`), or I/O wait—not the same as CPU busy.

## Exercise 3

Measure; for Go set GOMAXPROCS to quota cores; for Java size pool near cores for CPU work, higher only if blocking I/O dominates and DB allows.
