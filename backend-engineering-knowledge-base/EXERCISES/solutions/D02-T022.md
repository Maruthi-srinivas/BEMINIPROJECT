# Solutions — D02-T022

## Exercise 1

Dynamic programming solves a problem by combining answers to overlapping subproblems and storing each answer once. It needs optimal substructure and a recurrence you can evaluate in an order that respects dependencies. Memoization is top-down. Tabulation is bottom-up. The state must be small enough to store.

The failure enters when a step is skipped or repeated without an invariant: a state that forgets a dimension the recurrence needs, so two different futures share one stored answer.

Mark that step on the diagram. If you cannot point to a step, the explanation is still a definition, not a mechanism.

## Exercise 3

Choose Dynamic programming when subproblems overlap and the state fits in memory.

Avoid it when the recurrence is wrong or the state space is exponential in a dimension you cannot drop.
