## Exercise 1

```python
from types import MappingProxyType


def freeze_config(cfg: dict) -> MappingProxyType:
    """Return a read-only top-level view. Nested lists and dicts remain mutable
    unless callers deep-copy first; this function does not recurse."""
    return MappingProxyType(dict(cfg))
```

Acceptance notes: `freeze_config({"a": 1})["b"] = 2` raises `TypeError`. Mutating `freeze_config(cfg)["tags"]` if tags is a list still mutates the underlying list shared with `cfg`. Docstring states shallow freeze policy. Not executed as a standalone test file.

## Exercise 2

Tests alias the same module-level dict by reference; order-dependent mutations leak between tests. Fix: reset `CACHE.clear()` in a pytest autouse fixture, replace module cache with `functools.lru_cache` on pure functions, or inject a fresh dict per test via dependency injection. Copy-on-read (`return dict(CACHE)`) prevents callers from mutating shared state but still requires reset of logical entries between tests.

## Exercise 3

At 10k RPS, copying a small metrics dict (dozens of keys) is on the order of hundreds of microseconds or less in CPython if values are ints—often acceptable for external API snapshots. A live view avoids allocation but lets callers mutate internal state and shows torn reads under concurrent updates without a lock. Prefer immutable snapshot or copy per response for public API; keep live reference for in-process admin with synchronization. Publish consistency window (point-in-time) in docs if copy is skipped.
