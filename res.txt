Created a feature-flag service with percentage rollouts (sticky hashing) and attribute rules, an OpenSearch log aggregator with source-token auth, and an in-memory KV store with TTL + WebSocket pub/sub.
Wrote pytest + httpx API tests for all services and automated them in GitHub Actions (matrix CI per service).

STAR story — Backend Systems Lab
Situation
I wanted interview-ready depth beyond CRUD APIs, so I built a portfolio of backend systems that mirror what production teams actually run — auth, rate limiting, queues, gateways, caching, and observability — instead of one simple app.

Task
Design and ship 10 independently deployable FastAPI services, each with its own data store, Docker Compose stack, tests, and clear operational concerns (security, durability, performance), so I could speak confidently about tradeoffs in backend interviews.

Action

Split work into focused services (auth, URL shortener, rate limiter, file storage, notifications, job queue, API gateway, log aggregator, feature flags, mini Redis).
Implemented JWT + rotating refresh tokens, Argon2 hashing, RBAC, and Google OIDC on the auth service.
Built Redis rate limiting with Lua token-bucket and sliding-window algorithms for atomic checks under concurrency.
Used RabbitMQ for notifications with retries, backoff, and a DLQ; used Redis for a job queue with workers and scheduled jobs.
Added an API gateway with JWT verification, reverse proxy routing, and local rate limiting.
Built signed-URL file access (HMAC), Redis-backed caching, OpenSearch log ingest, and sticky % feature-flag rollouts.
Containerized each service with Compose (Postgres/Redis/RabbitMQ/OpenSearch as needed) and added pytest + GitHub Actions CI.
Result
Delivered a working multi-service backend portfolio I can demo end-to-end, with concrete talking points on auth security, rate-limit algorithms, messaging reliability, and caching. It became my strongest interview project for backend roles because I can walk through real failure modes (token reuse, queue poison messages, cache inconsistency) with code I own.
