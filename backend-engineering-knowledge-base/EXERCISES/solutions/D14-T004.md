# Solutions — D14-T004

## Exercise 1

A topic is a named log. A partition is an ordered, append-only shard of that topic. An offset is a consumer's position in a partition. Ordering is guaranteed inside one partition, not across partitions. The partition count bounds consumer parallelism. Keys choose a partition. Changing the partition count changes key placement.

The failure enters when a step is skipped or repeated without an invariant: assuming a global order across partitions, or adding partitions and silently changing which consumer sees a key.

Mark that step on the diagram. If you cannot point to a step, the explanation is still a definition, not a mechanism.
